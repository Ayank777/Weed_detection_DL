# Weed_detection_DL
Weed detection YOLOv8 model with deep learning
we have implemented YOLOv8 model on the weed detection system

Installation & Setup
1️⃣ Clone the Repository
https://github.com/Ayank777/Weed_detection_DL.git
cd Weed_Detection_Project

2️⃣ Create Virtual Environment
conda create -n weed_dl python=3.9
conda activate weed_dl

3️⃣ Install Dependencies
pip install -r requirements.txt

<!-- If installation fails for OpenVINO
Run separately:
pip install openvino --upgrade -->

## ▶️ Run the Application

After installing dependencies, directly run:

python gui/gui_openvino.py
